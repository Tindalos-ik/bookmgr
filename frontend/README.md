# 青叶书房

Vue 3、TypeScript、Vite、Vue Router、Pinia 与 lucide-vue-next 构成的本机演示书房。无需后端接口，图书、封面与原创 TXT 短篇均随前端提供。

## 启动与构建

使用 Node.js 24，在项目根目录的 Windows 终端中运行：

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

打开终端输出的本地地址。生产构建运行 `npm.cmd run build`，本地预览运行 `npm.cmd run preview`。部署时将所有页面地址回写至 `index.html`，以支持历史路由直接访问。

## 阅读与管理

- 概览提供推荐图书和最近上架列表；全部图书支持书名/作者搜索、分类、排序和每页 8 本分页。
- 详情页显示资料与文件信息；有文件的图书可下载真实原创 TXT 短篇，无文件时明确提示。
- 收藏按身份独立保存，下架图书从公开目录、详情和收藏中隐藏。
- 管理员可新增、编辑、上下架与删除图书。价格允许零元；删除需再次确认，并清理所有用户收藏引用。
- 新书自动使用带当前书名的封面，不附阅读文件。编辑保留已有封面及文件，管理页不提供文件上传。
- 手机导航通过左上角按钮打开，支持 Escape 关闭；管理对话框支持 Tab 循环与 Escape 关闭。

## 浏览器数据

- `localStorage` 的 `qingye.books` 保存图书，`qingye.favorites` 保存按用户编号隔离的收藏。
- 仅对应存储键首次缺失时初始化种子；刷新保留图书修改和收藏，不覆盖已有资料。
- `sessionStorage` 的 `qingye.session` 仅保存当前标签页身份，不保存密码。退出移除会话，关闭标签页结束该标签页会话。
- 演示种子包含 12 本书，其中 11 本上架，3 本提供匹配书名的独立原创短篇。
- `createdAt` 记录加入时间，`publishedAt` 记录首次或重新上架时间；编辑已上架图书不会改写上架时间。
- 浏览器存储读写、解析等未预期故障会停止应用并显示错误。请检查控制台与浏览器存储权限，解决原因后刷新；应用不会以替代数据继续编辑。

## 目录说明

- `src/stores`：图书、身份、收藏和首次种子。
- `src/router`：页面路由及演示权限守卫。
- `src/views`：登录、阅读、收藏和管理页面。
- `src/components`：导航布局、书封与图书卡片。
- `src/assets`：公共及书库样式。
- `public/covers`：原创本地 SVG 书封。
- `public/samples`：原创 TXT 短篇，文件大小按实际 UTF-8 字节记录。
