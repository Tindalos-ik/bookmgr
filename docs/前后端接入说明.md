## 首次准备与启动

后端需 Python 3.12+、uv，前端需 Node.js 24。先在 `backend/.env` 配置已有 MySQL 连接，字段参考 `backend/.env.example`；不要为此新建数据库。

首次在项目根目录执行：

```powershell
cd backend
uv sync --frozen
uv run --no-sync alembic upgrade head
cd ../frontend
npm.cmd ci
cd ..
```

日常双击根目录 `start.cmd`，在前后端窗口查看日志；后端会先执行迁移再启动。已有服务占用 8000 或 5173 时，先到对应窗口按 Ctrl+C 停止，再启动，避免端口冲突。前端地址：<http://localhost:5173/>；接口文档：<http://localhost:8000/docs>。

## 登录与常用操作

| 角色 | 用户名 | 密码 |
| --- | --- | --- |
| 读者 | reader | reader123 |
| 管理员 | admin | admin123 |

以上公开凭据仅供开发演示，请勿填写敏感资料。

读者可搜索图书、按分类筛选、排序和分页，收藏图书，并下载有附件的 TXT。管理员可增改删图书资料及上下架；新建图书没有附件，当前不支持上传。删除图书需确认，删除后也会移除该书的收藏。

## 数据与会话

图书与收藏保存在当前 MySQL。浏览器只在当前标签页保存登录令牌；刷新后可继续读取服务端资料，退出会撤销会话。已有本地演示图书和收藏不会自动导入数据库。

## 接口与开发命令

接口细节见 [Swagger 文档](http://localhost:8000/docs)。使用 Swagger 时执行 `/auth/token`，复制响应中的 `data.access_token` 并粘贴到 Authorize。

- 后端测试：在 `backend` 执行 `uv run --no-sync pytest -q`。
- 前端构建：在 `frontend` 执行 `npm.cmd run build`。
- 正式部署配置 `/api` 反向代理或 `VITE_API_BASE_URL`，使用 HTTPS 并替换公开演示凭据。
