## 首次准备与启动

后端需 Python 3.12+、uv，前端需 Node.js 24。先在 `backend/.env` 配置已有 MySQL 连接，字段参考 `backend/.env.example`；不要为此新建数据库。

首次在项目根目录执行：

```powershell
cd backend
uv sync --frozen
cd ../frontend
npm.cmd ci
cd ..
```

日常双击根目录 `start.cmd`，在前后端窗口查看日志。已有服务占用 8000 或 5173 时，先到对应窗口按 Ctrl+C 停止，再启动，避免端口冲突。前端地址：<http://localhost:5173/>；接口文档：<http://localhost:8000/docs>。

## 账号操作

用户可在登录页点击“注册账号”注册；注册成功后返回用户登录页。普通账号注册后固定为读者，不自动登录。管理员登录入口为 `/admin/login`。登录后在左侧菜单选择“修改密码”（手机先打开左上角菜单）；成功后需使用新密码重新登录。

## 创建管理员账号

从项目根目录执行：

```powershell
cd backend
uv run --no-sync python create_admin.py
```

按提示填写用户名、密码和确认密码。输入的密码不会回显；用户名重名时会拒绝创建。创建成功后，前往 <http://localhost:5173/admin/login> 登录。

## 数据与会话

图书与收藏保存在当前 MySQL。浏览器只在当前标签页保存登录令牌；刷新后可继续读取服务端资料，退出会撤销会话。已有本地演示图书和收藏不会自动导入数据库。

## 接口与开发命令

接口详情见 [Swagger 文档](http://localhost:8000/docs)。注册为 `POST /auth/register`，密码修改为 `PUT /auth/password`；修改成功会撤销所有会话。

- 后端测试：在 `backend` 执行 `uv run --no-sync pytest -q`。
- 前端构建：在 `frontend` 执行 `npm.cmd run build`。
- 正式部署配置 `/api` 反向代理或 `VITE_API_BASE_URL`，使用 HTTPS。
